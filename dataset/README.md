# MAVEData-3K

**MAVEData-3K** contains **3,000** blockout–video pairs for training blockout-conditioned video generation models.

Each pair includes:

- an editable reconstructed blockout scene  
- a frame-aligned blockout video rendered with the recovered camera trajectory  

## Access

| Content | Access |
| --- | --- |
| Our annotations / derived metadata | **Public** — [`yfChang/MAVE`](https://huggingface.co/datasets/yfChang/MAVE) |
| Film-related media | **Gated** — [`yfChang/MAVE-film`](https://huggingface.co/datasets/yfChang/MAVE-film) (request access) |
